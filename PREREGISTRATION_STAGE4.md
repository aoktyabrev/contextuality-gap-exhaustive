## 0.1. Методологическое замечание, записанное ДО счёта

**Метрика «Δ_max / медиана топ-100» сцеплена с размером выборки.** Топ-100 — это срез
фиксированного размера из хвоста; чем больше графов с Δ > 0, тем тоньше этот срез в
терминах квантилей и тем ближе его медиана к максимуму. Отношение поэтому **механически
стремится к 1 при росте N**, независимо от какой бы то ни было структуры.

Числа графов различаются на три порядка (498 → 16 533 → 975 338), а наблюдаемый ряд
1.98 → 1.52 → 1.14 убывает ровно в ту сторону, куда толкает этот эффект. Следовательно
**сам по себе этот ряд не является свидетельством аномалии**, и постановка стадии на нём
одном не стоит.

Бриф 4.e фиксирует метрику и запрещает её менять по ходу — это соблюдается: она
считается и печатается как есть. Но выводы делаются **не по ней**, а по блоку 4.a,
который сравнивает наблюдаемый максимум с предсказанием хвоста **при фактическом N**,
то есть устраняет сцепление. Это и есть причина, по которой бриф ставит 4.a первым.

## 1. Блок 4.a — экстремальная статистика

### 1.1. Метод, зафиксированный до счёта

Для каждого n берутся все значения Δ > 0 (числа выше). Далее:

1. **Порог** u — 90-й процентиль этих значений.
2. **Из выборки для подгонки исключается верхушка**: десять наибольших значений
   не участвуют в подгонке. Это делает предсказание максимума **вне-выборочным** и
   снимает главную ловушку — подгонку хвоста по той самой точке, которая проверяется.
3. К превышениям над u подгоняется обобщённое распределение Парето (GPD) методом
   максимального правдоподобия; параметры ξ (форма) и σ (масштаб).
4. Предсказание максимума при фактическом N: распределение максимума N независимых
   значений из подогнанного хвоста есть GEV; печатаются его медиана и центральный
   интервал 5–95 %.
5. **Наблюдаемый максимум переводится в процентиль этого предсказанного распределения.**
   Это и есть «отклонение в единицах разброса предсказания», о котором просит бриф,
   в форме, не требующей симметрии распределения.

**Оговорка, записанная заранее:** значения Δ по графам не являются независимой выборкой —
это детерминированное множество. Экстремальная статистика применяется здесь как
описательная модель хвоста, а не как вероятностное утверждение о случайном эксперименте.
Поэтому вывод формулируется как «наблюдаемый максимум согласуется / не согласуется с
формой хвоста того же распределения», а не как p-значение.

### 1.2. Что считается каким исходом — до счёта

| исход | вывод |
|---|---|
| n = 10 ниже 5-го процентиля предсказания **и** n = 8 выше 95-го | обе аномалии реальны и структурны |
| оба внутри 5–95 % | «аномалия» есть эффект размера выборки; стадия закрывается отрицательно |
| ниже только n = 10 | аномальна десятка; восьмёрка — артефакт малой выборки |
| выше только n = 8 | аномальна восьмёрка; вопрос о десятке снимается |

### 1.3. Предсказания

| # | предсказание | обоснование |
|---|---|---|
| E1 | **n = 8 окажется ВНУТРИ интервала**, то есть его «аномальность» исчезнет | у восьмёрки всего 498 положительных графов — самая маленькая выборка из трёх, и разброс максимума при N = 498 велик; отношение 1.98 к медиане топ-100 при N = 498 означает, что топ-100 занимает пятую часть всей популяции, то есть «медиана топ-100» там — это вовсе не хвост |
| E2 | **n = 10 окажется НИЖЕ 5-го процентиля** | Stage 3 показал, что тело распределения при n = 10 выросло историческим темпом, а ранги 1–2 нет; если хвост подогнан по телу, он должен предсказать максимум выше наблюдаемого |
| E3 | n = 9 окажется внутри интервала | ничто в данных Stage 3 не выделяло девятку: её отрыв 1.52 лежит между 1.35 и 1.98 |

**E1 и E2 независимы и могут провалиться по отдельности.** Если провалится E2 — вся
постановка стадии закрывается отрицательно, и это записывается как результат, а не как
неудача.

## 2. Блок 4.b — кто стоит на верхушке десятки

Топ-10 при n = 10 разбирается теми же величинами, что и максимизаторы в Stage 3
(`runners/run_3b.py` уже это считает; данные в `results/report_3b.json`), и сравнивается
с топ-10 девятки. Новое здесь — сравнение **семейств**, а не отдельных графов:
доля разложимых «цикл + клика», распределение |Aut|, регулярность, число индуцированных C₅.

**Ожидание:** лидеры десятки не окажутся семейством C₆+K₃. Основание: у максимизатора
n = 10 разложения «цикл + клика» нет вовсе, он 4-регулярен, а те три графа из топ-10,
у которых разложение (6, 4) есть, стоят на плато 2/3, то есть являются продолжением
девятки, а не источником нового максимума.

## 3. Блок 4.c — продолжается ли конструкция C₆+K₃

Строятся явно и считаются Δ, α, ϑ и ранг в общем списке n = 10 для:

1. **C₇ + K₃**, каждая вершина треугольника соединена с парой вершин цикла на
   максимальном расстоянии (для нечётного цикла «антиподальной» пары нет, поэтому
   берутся обе вершины на расстоянии 3, и перебираются все неизоморфные способы);
2. **C₆ + K₄**, где четырём вершинам клики нужно раздать три антиподальные пары
   шестиугольника — перебираются все неизоморфные назначения;
3. **C₆ + K₃ плюс десятая вершина** во всех неизоморфных позициях (присоединённая к
   подмножествам вершин девятивершинного оптимума).

Для каждой конструкции печатаются α и ϑ **по отдельности**, чтобы видеть, что именно
ломается при переходе.

**Предсказание:** ни одна из конструкций не достигнет Δ_max(10) = 1/√2; лучшие из них
выйдут ровно на плато **Δ = 2/3**, то есть на девятивершинное значение. Основание: три
графа с разложением (6, 4) в топ-10 уже стоят на 2/3, а максимизатор к этому семейству
не принадлежит. Ожидаемый механизм: при добавлении вершин α растёт быстрее, чем ϑ.

## 4. Блок 4.d — дешёвые гипотезы

Проверяются и закрываются: зависимость отношения максимум/медиана от чётности n;
связь с α максимизатора (и не меняется ли α в топ-10 десятки); связь с d\*.

**Ожидание по всем трём — отрицательный ответ.** По чётности: точек шесть, из них по три
на чётность, и ряд 1.35, 1.98, 1.52, 1.14 не разделяется чётностью. По α: он равен 3 у
всех максимизаторов при 7 ≤ n ≤ 10 и у всех 50 графов топ-50 обеих больших стадий, то
есть попросту не варьируется и коррелировать не с чем. По d\*: Stage 2 уже показал
отсутствие связи степени поля с симметрией; d\* при этом равен 4 почти везде.
